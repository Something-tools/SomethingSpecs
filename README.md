# SomeSwap Specs

This repository contains contract specs, ABIs, addresses, and docs for SomeSwap.

## Structure

- `someswap-v1/`
  - `mainnet-beta/` and `testnet/` deployments
  - ABIs and addresses for v1
  - `archive/` contains historical or audit builds
  - `typescript-examples/` contains integration examples
- `someswap-v2/`
  - `testnet/` deployments
  - ABIs, addresses, and protocol docs for v2

## How to use

- Addresses are stored in `addresses.json` under each network folder.
- ABIs are stored under `abi/` per contract.
- Additional docs live under `docs/`.

## Notes

- `archive/` folders are historical snapshots and may not be deployed.
